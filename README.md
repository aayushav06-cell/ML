## Topics Covered So Far

**Day 01:**
- What is Machine Learning?
- Types: Supervised, Unsupervised, Reinforcement
- Key concepts: Features, Targets, Training/Testing, Overfitting/Underfitting
- Python intro with linear regression example
- Common mistakes to avoid

**Day 02:**
- Data preprocessing: imputation, encoding, scaling, outlier handling
- Evaluation metrics deep dive: precision/recall/F1 tradeoff, ROC-AUC, confusion matrix
- Cross-validation with K-Fold and StratifiedKFold
- Algorithms: Logistic Regression, Decision Trees, K-Means
- End-to-end Titanic survival project with sklearn Pipelines
- Hands-on exercises

**Day 03:**
- Ensemble methods: Random Forest, Gradient Boosting, AdaBoost, Stacking
- Support Vector Machines: kernels (linear, RBF, polynomial), hyperparameters
- Hyperparameter tuning: GridSearchCV, RandomizedSearchCV, validation strategies
- Regularization: L1 (Lasso), L2 (Ridge), early stopping
- Model comparison project: Iris classification with 6 algorithms
- Hands-on exercises

**Day 04:**
- Unsupervised learning: K-Means, Hierarchical clustering, DBSCAN
- Dimensionality reduction: PCA, t-SNE
- Neural networks: Perceptron, MLP, activation functions, hyperparameters
- Anomaly detection: Z-score, IQR, Isolation Forest, LOF
- Model deployment: saving/loading with joblib, production pipeline, monitoring
- End-to-end project: Mall Customers Segmentation

**Day 05:**
- Deep learning frameworks: TensorFlow, PyTorch, JAX
- Convolutional Neural Networks (CNNs): architecture, ResNet, VGGNet
- Data augmentation for CNNs
- Recurrent Neural Networks: RNN, LSTM, GRU, Seq2Seq models
- Natural Language Processing: word embeddings, Word2Vec, BERT, text generation
- Transfer learning: fine-tuning pre-trained models, LoRA
- Advanced topics: GANs, autoencoders, reinforcement learning basics
- Production deployment: TorchScript, ONNX, FastAPI serving, model monitoring
- Hands-on exercises: MNIST CNN, text generation, BERT fine-tuning
